# 曲线编辑与 MMV 窗口验收

曲线实现提交为 `a017903`，公共曲线核心为 `f576e96`。随后 `7d783ca` 将它与 Bullet3 后端合并。正式入口为 `build/Release/MikuMikuDance.exe`，同目录安装兼容版 `MMV.dll`；纯 DX12 版位于 `build/mmv/dx12/Release/MMV.dll`。操作说明见[曲线编辑器](ANIMATION_CURVE_EDITOR.md)，后端组合版本见 [Bullet3 集成验收](MMV_BULLET3_MAIN_INTEGRATION.md)。以下哈希及性能对照对应曲线版本快照，不混用后续 Bullet3 构建。

## 修复内容

- 参数浮窗在 `WM_NCCREATE` 时保存真实窗口句柄，使非客户区计算调用正确的 `DefWindowProc`。窗口恢复标题栏、缩放边框，并居中于所属窗口、限制在显示器工作区内。
- 相同语言不重复填充下拉列表；枚举列表展开时跳过逐帧数值同步。
- 分配表与参数区随窗口高度分配空间，窄窗口工具栏换行，说明文字预留两行，空关键帧列表不再占用固定的大块高度。
- 「烘焙」位于「帮助」左侧。语言切换、模型载入、播放和重置通过 About 命令 201 定位帮助菜单，不依赖旧序号 7。
- 附件、摄像机、灯光、自阴影、重力，以及 MMV 参数共用曲线浮窗。支持增删帧、切线、贝塞尔手柄、所选通道烘焙及 VMD 尾部扩展。模型表情入口未纳入本次交付。

## 实际程序验证

`tests/mmv_ui_integration.cpp` 链接生产 MMS 核心，创建真实 DX9 设备，由宿主加载实际 MMV DLL，加载 Rou PMX 和外置 Bullet3 参数定义。通过真实菜单和按钮打开窗口，使用 `WM_PRINT` 向内存 DIB 绘制，不读取桌面。测试只读参数定义，不以此声称验证 Bullet3 物理后端。

`.local/artifacts/mmv-curve/ui-integration-complete/` 保存三语、800/560 像素窗口、参数浮窗及宿主/MMV 曲线窗口的实际绘制图。隐藏公共控件的 `WM_PRINT` 可能省略组合框文字，因此同时读取原生控件状态验证。

- 引擎下拉展开后，连续 60 次生产 `FrameDriver` 调用仍保持展开，选中项不变。
- 三语参数浮窗均位于 `(106,144)`，大小 `748×551`；标题栏返回 `HTCAPTION`，左边框返回 `HTLEFT`，窗口移动成功。这里验证原生移动入口与窗口位置，不声称进行了人工鼠标拖动。
- 三语菜单均为烘焙序号 7、帮助序号 8；MMV/MME 各出现一次。
- MMV DLL 和宿主各自创建了曲线画布 1020 与贝塞尔面板 1031。

旧版实际 EXE 现场保存在 `ui-probe/mmv-only1/`：参数窗口位置 `(0,0)`，标题栏命中测试返回 `HTCLIENT`。该记录由 `tools/run_mmv_layout_probe.py` 产生；旧版模态浮窗的下拉持续测试没有复现逐帧关闭，不能替代新版嵌入参数区的回归结果。

## 前后耗时对照

使用独立生产构建 `6c11054` 与 `a017903`，1280×720、20 帧预热、90 帧采样，两个场景各进行两轮 ABBA，合计 16 次运行。`performance/manifest.json` 保存源码、EXE、素材、CMake 缓存、命令与原始样本；两个版本的程序和资源在采样开始时即已复制固定，后续主分支合并不影响本组来源。

| 场景 | 前版中位耗时（范围） | 曲线版中位耗时（范围） |
| --- | --- | --- |
| 单实例草地 | 203.351 ms（197.304–218.235） | 212.461 ms（198.109–222.708） |
| 移动面部镜头 | 8.860 ms（6.920–11.232） | 7.912 ms（6.872–10.068） |

这是等待 GPU 完成后的批次每帧耗时，不是播放 FPS 或纯 GPU 时间。草地增加 4.48%，面部减少 10.71%，范围重叠且存在后台负载波动，不宣称性能提升，也不能据此排除小幅回归。测试不含 MMV 效果或 Bullet3 物理负载，后者以独立集成记录为准。
