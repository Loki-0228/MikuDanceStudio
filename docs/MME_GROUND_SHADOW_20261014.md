# MME 地面阴影异常加深修复

部分材质使用 MME、其余材质使用原生绘制时，同一模型的地面投影会出现深浅不同。YYB Hatsune Miku NT 的原配特效可复现此问题。

地面阴影通道原先只设置材质的环境色。原生绘制读取环境色，而 MME 从漫反射色取得 `EgColor`，未同步的漫反射色为黑色，因而使 MME 材质的阴影异常加深。

`src/render/accessory.cpp` 在配件投影绘制和投影材质恢复处同步环境色与漫反射色的 RGB。原有阴影亮度、透明混合开关和 alpha 值保持不变。
