# 云透明浮点合成与目标 alpha 修复

本轮始于 2026-09-26，验收记录完成于 2026-09-27。本记录对应 `fix/cloud-precision` 的修复阶段；该分支已于 2026-09-27 合入本地 `main`，详见[主分支集成记录](CLOUD_SORT_MAIN_INTEGRATION_2026-09-27.md)。下述测量仍对应当时的前后 build。

## 结论与边界

已修复两个独立缺陷：透明层逐层写回 8 位目标导致低 alpha 贡献因舍入而丢失；同一混合因子错误地作用于目标 alpha，导致已经合成天空的云图再次带透明度。Toon 调整不能修复这两项。另修复分层预算耗尽时只留下远层、漏掉最近层的问题。

真实云图的 alpha 已恢复，原始 RGB 最大仅变化 3/255，因此本轮不能宣称云内部剩余灰暗已解决，也不能把它再次归因于 Toon。此前法线实验只描述了局部受光变化，不足以解释用户所指全部发黑。

当前 `cloud.pmm` 的天空来自 `UserFile/Model/Sky/Blue.bmp` 背景图片。工程加载一个 ToonCloud PMX 和一个 ikParticle 配件，ToonCloud 贴图表只有 `cloud.tga`、`CToon.png`，没有单独的天空球几何。背景图片经 `DrawPreModelQuads` 在模型前绘制、关闭深度测试，不加入透明三角形集合。不能将本场景的问题表述成天空球三角形排序失败；其他真正的天空球或自定义效果需独立验证。

## 为什么调白 Toon 后图片仍会发黑

旧混合把 RGB 与 alpha 都用 `SRCALPHA / INVSRCALPHA`：

- RGB：`Cs * As + Cd * (1-As)`。
- 错误的目标 alpha：`As * As + Ad * (1-As)`。
- 正确的目标 alpha：`As + Ad * (1-As)`。

当目标原本已是不透明天空（Ad=1），正确结果仍应为1。旧式会把目标 alpha 压低。导出的 PNG 把已经含天空的 RGB 和错误 alpha 一起保存；在深色底上再次显示时就会发暗。窗口内 RGB 与导出 PNG 的再次合成不能混作一个证据。

修复前纯白 Toon 控制图中，云内部 RGB 三通道均至少250的117990像素，alpha范围42–178，中位85；对应原 Toon 的 alpha 分布相同。改变 Toon 只改变色值，未修正该错误。

## 实现

保留原片段选层、同深度稳定编号、原材质与光照输出。使用两组私有 FP32 颜色/最近深度目标，每层先复制前一组，再在 shader 中手算预乘颜色与累计 alpha；未完成时原颜色和深度保持不变。全部分层完成才以 `ONE / INVSRCALPHA` 一次提交并恢复最近有效深度。未完成或出错则重新走完整几何回退，不保留半份结果。

最初尝试直接对 FP32 目标做硬件混合，RTX4070 Laptop 的 D3D9 能力查询不支持，实际发生回退。最终实现不依赖该能力。

普通深度直接用于只读遮挡测试。MSAA 深度不能与单采样 FP32 目标混绑，因此每层先在同采样类型、同质量级别的 FP16 掩码目标上按原深度测试，再 resolve 为覆盖率；源颜色与累计结果仍为 FP32。设备不支持所需资源或 resolve 失败时完整回退，不关闭抗锯齿或遮挡测试。

MSAA 掩码保留像素覆盖比例，仍不是每个子采样独立保存完整透明链。部分遮挡边界、任意自定义 shader、配件 `.x` 与模型的统一全局排序不在本轮准确性证明内。标准/高/极高层上限仍为1024/2048/4096，菜单及 PMM v2 精度字段未改；标准档还不能视作已完成性能验收的最终默认值。

## 两版 build 对照

前版 `baseline/cloud-composite` 的 `0b2ad75`，生产渲染代码固定于浮点修复前；后版 `fix/cloud-precision` 的 `6f01562`。`e73eaaf` 引入私有浮点累积，`6f01562` 增加 MSAA 遮挡。两版均独立构建 Release、MME 后台驱动及同一回归源文件；VS2022/v143/x64，性能与诊断编译选项关闭。对照启动时前树干净、后树只有文档修改。

MME 加载、Cloud.fx 未启用，ikParticle.fx 保留。相机、1076×606视口、原模型、动作/物理、效果与驱动相同；原 Toon 与纯白 Toon 各自做两轮反向交替采样，每次预热2帧、采样5帧。计时为等待 GPU 完成后的批次毫秒，不是播放 FPS。

| 条件 | 修复前两轮 ms/帧 | 修复后两轮 ms/帧 |
| --- | ---: | ---: |
| 原 Toon | 395.370 / 409.993 | 587.468 / 637.818 |
| 纯白 Toon 控制 | 438.657 / 428.216 | 617.692 / 649.581 |

性能不合格，未声称优化。后台测试不显示或置顶窗口，图片来自渲染目标回读。性能采样无额外分层读回或 trace；另一次诊断核对实际逐层路径。

同一云内部掩模118099像素，原 Toon RGB均值从 `(230.27,234.95,240.35)` 变成 `(230.45,235.12,240.49)`；alpha从42–178恢复为全255。比较区域 `(323,25)` 至 `(1399,500)` 中，alpha小于255的像素从164564降至0。掩模由纯白 Toon 的 RGB>=250定义，仅用于通道比较，不是排序正确性的独立参考。

## 回归结果

| 用例 | 修复前 | 修复后 |
| --- | --- | --- |
| 256层黑色，alpha=1/255，白底 | RGB127，A128 | RGB93，A255；解析值93.26 |
| 512层黑色，alpha=2/255，白底 | RGB63，A65 | RGB5，A255；解析值4.53 |
| 1152层、最近绿色层、标准预算 | 黑色，漏近层 | `(0,128,0)`；日志确认1024层未完成后回退 |

| 不透明面夹在两透明面之间 | 通过 | 通过；隐藏的远层颜色未混入 |

以上三项专项分别在单采样与4x MSAA实际设备运行；MSAA不支持时测试明确失败，不能以单采样冒充。alpha、描边、材质顺序既有测试通过。完整遮挡回归前后均有8个既存 shadow-alpha 失败点，没有记为全量通过。
