# StageNoRay 模型计算优化

本轮针对 `D:/MMD-Next/tests/ToonGlass_Ray/UserFile/StageNoRay.pmm` 优化模型计算。工程包含 6 个模型，共 737,533 个顶点，其中单个舞台模型有 471,122 个顶点。诊断样本中，表情与蒙皮合计约占每帧 10 毫秒，降低预览尺寸不能减少这部分计算。

本报告中的前后版本提升不代表已经解决「降低分辨率后帧率没有明显上升」。同一版本的 100% 与 25% 对照仍没有明显差别，补充定位见下文。

后续已增加 GPU 分段计时。相邻两轮复测中，25% 预览的 GPU 绘制区间比 100% 缩短约 19%，整帧耗时仍约 16 ms。测量方法、运行波动和完整结果见 [StageNoRay GPU 绘制耗时](STAGE_NO_RAY_GPU_TIMING_20261015.md)。

## 降低分辨率的补充定位

在保留工程设置、关闭物理、固定第 0 帧的隐藏 MME 宿主中，按 100%、25%、25%、100% 顺序采样，每段至少 4 秒。绘制拦截与模型处理计时只在采样区间外启用。

| 项目 | 100% | 25% |
| --- | ---: | ---: |
| 主画面实际渲染尺寸 | 725×406 | 181×102 |
| 宿主阴影实际尺寸 | 8192×8192 | 2048×2048 |
| 每帧模型更新数 | 6 | 6 |
| 每帧观察到的绘制调用 | 618 | 619 |
| 每帧观察到的图元提交数 | 2,893,587 | 2,893,589 |
| 模型更新调用的 CPU 经过时间，两个诊断帧 | 7.07、7.20 ms | 7.39、7.07 ms |
| 含最终 GPU 排空的平均帧耗时 | 14.80 ms | 14.61 ms |

像素数量已减少约 94%，模型处理和几何提交量没有随之减少。25% 多出的一次绘制、两个图元用于放大预览。MME 的屏幕相关目标会缩放，但同时仍存在 1024×1024、512×512、256×256、1×1024 等固定目标。特效文件中包含固定尺寸的软阴影、亮度统计、材质贴图处理和粒子数据；不能只按纹理尺寸统一缩小这些资源。

这组数据说明主画面缩放已生效，但固定工作量限制了收益。单次 100% 与 25% 的平均差约 1.3%，不能作为明显提速的证据。模型更新计时包含函数内的等待，并非纯 CPU 指令时间；图元数统计覆盖 `DrawPrimitive`、`DrawIndexedPrimitive` 和 `DrawPrimitiveUP`，没有把它解释为最终可见三角形数。此轮没有测动画播放帧率或独立 GPU 阶段耗时。

曾试用直接拷贝替换预览放大绘制。它未通过与原实现的逐像素一致性检查，已撤回，正式程序仍保留原放大方式。本次补充没有新增已验证的性能修复。

有效记录位于 `.local/artifacts/stage-scale-20261015/trace-restored/`，测试程序 SHA-256 为 `5ff99b0155e0a39c75a675281f8e9b346e314cf2845e1cc11e7f52fe865cdeaf`。运行正常退出，源 PMM 校验值未变。`trace-work/` 含已撤回的实验实现，不用于上述结论。

## 实现

- 大型 PMX 的位置表情及五类 UV 表情按顶点范围分给工作线程。每个顶点只归一个线程处理，恢复、直接表情和组合表情仍按原顺序执行。重复索引不会引入并发写入，也不会改变浮点累加顺序。
- 单骨骼蒙皮同时计算 XYZ，保持原来的乘加顺序。刚性骨骼和带缩放、剪切的骨骼都保留原有法线规则。不支持该 x64 路径的构建继续使用标量实现。
- 小模型保持串行表情计算。大型模型沿用现有蒙皮工作线程数量，上限为 8，并保留用户设置的线程上限。

本轮没有跨帧缓存模型结果，没有省略顶点、模型或材质，也没有修改工程的画质设置。计算不依赖 NVIDIA 接口，可在支持这些指令的 AMD x64 CPU 上运行；本轮未进行 AMD 实机性能测量。

## 正式配置对照

原生与真实 MME 各运行一组旧版、新版、新版、旧版对照。基线包含上一轮阴影范围与 SMAA 菜单修改，新版增加本轮的蒙皮与并行表情计算。

两侧均关闭 `MIKUDANCESTUDIO_PERF` 和 `MIKUDANCESTUDIO_DIAG`。每轮按 100%、25%、25%、100% 预览顺序测量，每段预热 0.5 秒、采样至少 4 秒，并在边界等待 GPU 完成。保留工程自身的抗锯齿和阴影设置，隐藏地面网格，关闭物理，固定第 0 帧重复绘制。截图在计时结束后读取。

下表按总耗时除以总完成帧数合并，包含 GPU 等待。该指标不是动画播放帧率。

| 路径 | 预览比例 | 旧版耗时 | 新版耗时 | 耗时下降 |
| --- | ---: | ---: | ---: | ---: |
| MME | 100% | 17.64 ms/帧 | 15.76 ms/帧 | 10.66% |
| MME | 25% | 17.43 ms/帧 | 15.75 ms/帧 | 9.61% |
| 原生 | 100% | 17.07 ms/帧 | 14.04 ms/帧 | 17.79% |
| 原生 | 25% | 16.87 ms/帧 | 14.74 ms/帧 | 12.62% |

显卡为 RTX 4070 Laptop GPU。MME 同版本样本极差约为中位数的 3.8%～6.2%，原生为 9.1%～15.4%。尤其是原生组，运行波动较大，不能把平均值视为固定提升比例。原始逐段数据、二进制校验值和设置见 [对照数据](STAGE_NO_RAY_PERFORMANCE_20261015.json)。

## 验证范围

- 单骨骼计算通过 20,000 组与原标量实现的逐位比较，并通过既有刚性、缩放、剪切、混合蒙皮及 CPU/GPU 数学检查。
- 并行表情通过 6 组姿态、每组 65,539 个顶点的逐位比较，覆盖不整除的线程范围、重复顶点、组合表情、五类 UV、无效索引及权重归零后的恢复。
- 原生和真实 MME 抗锯齿回归各通过 854 项，包括相机运动、骨骼变形、TAA、SMAA T2x 和菜单选择。
- PMD/PMX 描边相机空间、宽度与 GPU 输入检查通过。
- 八轮正式对照均正常退出，源 PMM 的校验值保持不变。

原生 25% 预览的两次截图在四轮间均逐像素一致。原生 100% 和 MME 截图存在跨次差异，旧版与旧版之间也有差异，因此不将这些截图记为逐像素一致通过。具体差异数量与区域保存在对照数据中。模型计算的数值一致性由上述独立回归确认。
