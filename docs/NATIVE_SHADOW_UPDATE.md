# 原生阴影与 SDK 移除记录（2026-10-06）

MMS 的 SM3 原生阴影改用比较结果过滤，并按接收面的深度梯度修正采样位置。实现参考 MMN 原生渲染所沿用的 MMV4MMN 阴影代码，包括 `src/mmv/mmd_default_shader.hpp` 中的比较过滤和接收面修正。

## 开关与模式

| 设置 | 保留的行为 |
| --- | --- |
| 美影关闭 | 2048 × 2048 阴影贴图 |
| 美影开启 | 4096 × 4096 阴影贴图 |
| 模式 1 | 原有投影范围、变换与 SKII1 深度尺度 |
| 模式 2 | 原有投影范围、变换与随纵向坐标变化的 SKII2 深度尺度 |

过滤器读取实际分配的贴图尺寸，透明剥离渲染也复制这一参数。模式 1、2 的投影矩阵和阴影距离控制未改成自动包围盒拟合。SM2、地面投影阴影和投影者的透明裁剪逻辑保持原样。

## SDK 移除范围

删除独立 MMV SDK 的头文件依赖、插件宿主、渲染接管、菜单接入和专属接入测试。MMS 不再加载 MMV.dll，也不再需要 `MMV_INCLUDE_DIR`。原生网格采集、ABC 导出和缓存回放保留在 `src/render/native_mesh.cpp`。

MMV 分层烘焙入口已移除。旧分层缓存的格式检查与纯数据转换代码仍保留；需要 MMV 运行时的操作会拒绝执行。旧处理器配置字段继续读取，以免破坏项目文件兼容性。

## 验证结果

- Release 构建及删除 `MMV_INCLUDE_DIR` 缓存后的 CMake 配置通过。
- `native_shadow_tests` 在隐藏 D3D9 HAL 设备上编译生产 SM3 着色器并回读像素。两种测试贴图尺寸、两种模式、三种平面斜率的自阴影检查全部通过，材质透明度保持正确。
- 阶跃遮挡边界保留明暗两侧，并产生有限宽度的过渡。原着色器在同一组检查中有 8 项失败，新着色器为 0 项失败。
- 模式差异检查中，相同深度间隔的中心像素在模式 1 为 255、模式 2 为 51，两种测试尺寸均如此。
- 四种真实模型组合均确认请求模式生效，美影分别分配 2048、4096。相同美影设置下两模式的图像不同；相同模式下两种美影设置的图像也不同。
- 原生骨骼烘焙、帧率重映射、网格缓存和 ABC 导出后重新打开工程的回归通过。
- 低透明度叠加专项通过。完整透明遮挡回归前后均失败 77 项，失败明细一致；该回归未通过，不能作为本次完整透明效果验收。

## 性能样本与限制

前后两侧均从同一份移除 SDK 后的生产源码构建，只替换 SM3 阴影资源。基线提交为 `b239a38edb272ba36cd74629d09ca8c5ce344952`，未提交源码差异、构建日志和文件哈希保存在下述产物目录。这一对照只衡量阴影变化，不衡量 SDK 移除的性能影响；原 SDK 已缺失，无法构建此前的 SDK 接入版本。

同一 Rou PMX、相机、960 × 720 视口、CPU 蒙皮与原有物理配置，预热 30 帧、采样 180 帧，前后交替执行 3 轮。显卡为 RTX 4070 Laptop GPU。下表记录等待 GPU 完成后的整批每帧耗时，单位毫秒，格式为中位数（最小值—最大值）；不是播放 FPS 或独立 GPU 阶段时间。

| 设置 | 修改前 | 修改后 |
| --- | --- | --- |
| 美影关，模式 1 | 2.959（2.955—3.169） | 3.258（3.098—3.945） |
| 美影关，模式 2 | 3.088（2.876—3.412） | 3.013（2.843—3.512） |
| 美影开，模式 1 | 3.083（2.930—3.219） | 3.133（3.049—3.287） |
| 美影开，模式 2 | 3.149（3.001—3.487） | 3.138（2.948—3.511） |

样本波动较大，模式 1 关闭美影时中位耗时增加约 0.30 毫秒。本次侧重阴影质量，不声称性能提升。真实场景的前后回读图均含同一黑色矩形遮挡，整幅场景图像验收尚未完成；上述计时仅作为相同负载下的参考，不能据此宣称完整画面性能验收通过。早期 `*-mode1` 样本的相机参数顺序错误，已排除，原始文件保留。
