# 表情下拉列表宽度

眼、眉、嘴和其他四组表情下拉列表默认宽度调整为 240 像素。展开时按当前控件字体测量完整名称，预留边距及滚动条宽度，并限制到当前显示器工作区宽度。

测量在每次展开时执行，因此模型切换、语言切换和字体变化后的名称也会参与计算。

四组表情名称行的前后箭头、曲线入口和下拉框使用相同的上边缘与高度。布局读取原生下拉框的实际收起高度，因此字体或主题改变时，相邻按钮也会同步调整。各列的水平位置保持原有布局。
