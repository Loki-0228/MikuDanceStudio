# MME 自阴影滤波与两种构建档

完整包采用已确认的候选效果：默认阴影恢复 9.32 的线性深度采样和明暗过渡，同时保留模型边界防裁切与动态采样。最小包采用修改前参考代码的阴影投影和 SM2、SM3 着色器，包括范围过小时的原有裁切行为。

## 完整包

`skin_effect_sm3.fx` 的 `DefSampler` 使用 `LINEAR`。模式 1 按深度差乘以 1500，再减去 0.3 后限制到 0 至 1。模式 2 使用 8000，并乘以阴影贴图的纵向坐标。材质明暗混合恢复线性插值，不再使用候选之前的比较结果重建、接收面导数修正和 `smoothstep`。

投影从实际 9.32 的光源变换恢复，再由 `FitReferenceShadowProjection` 扩展到模型和附件边界；异常光向才使用安全投影。`UpdateAdaptiveShadowMap` 根据有效覆盖范围、屏幕尺寸及视距选择采样分辨率。两种模式都保留最高精度下的覆盖保护；切换动态采样不另存一套阴影范围。

YYB Miku NT 的同名 EMD 会为衣服、袖子和裙子自动加载 `AlternativeFull` 系列特效。其采样器未完整声明过滤状态，因此宿主的线性采样状态仍必须正确。模型、EMD 和外部特效文件未修改。`MdsShadowMapSize` 每帧取当前 GPU 纹理尺寸。默认原生滤波不依赖该参数；可选「滤波加强」使用它把样条核换算为实际纹素，并结合屏幕足迹调整积分范围。高分辨率增加参与纹素数，不把少量采样点直接拉开。此开关只在完整包的 SM3 路径提供，默认关闭。

## 最小包

`mmd932` 构建档直接使用 `res/assets/original/skin_effect_sm2.fx` 和 `skin_effect_sm3.fx`。两份资源与 `D:/MMD-Next/refs/MikuDanceStudio-main/res/assets/` 中的对应源码在统一换行符后完全相同。原版分支的阴影投影计算也与该参考目录一致。

最小包保留模式相关的投影变换、深度范围、滤波及裁切，不调用完整包的边界拟合和动态采样。其他共享缺陷修复仍按原有构建规则保留。

## 验证记录

验证使用 RTX 4070 Laptop GPU。主要证据保存在 `.local/artifacts/mme-shadow-20261013/`：

- `native_shadow_tests`：模式 1、2 共 98 组 GPU 像素对照通过，包含低分辨率贴图、不同深度差、斜面、细遮挡物、子像素偏移和部分受光法线。SM2 的覆盖边界检查也通过。
- `approved-autofit/`：原版 MME 下，最高精度、两种模式、动态采样开关及相机平移共 8 组，所有测试顶点均在阴影覆盖范围内，范围值未被覆盖保护改写。
- `approved-dynamic-native/`：两种模式的近景、左右平移均使用 4096；远景降至 512。模型顶点在画面外时仍计入采样需求。
- `approved-mme-authored/`：真实 YYB 模型及其自带特效，在模式 1、2 和设备重置前后各检查 132 次绘制，其中 54 次继承宿主采样状态。四组过滤状态错误数均为 0。
- `approved-minimal-large/`：最小包在范围 0 的大模型夹具中，模式 1 有 8 个、模式 2 有 6 个顶点处于原有投影范围外；动态采样关闭。内嵌 SM2、SM3 资源与参考目录一致。这确认最小包没有套用完整包的防裁切。
- `original_profile_state` 的 32 项检查通过。`original_profile_ui` 的阴影滑块、原有 2048/4096 分辨率和动态采样控件隐藏检查均通过，但整个 UI 测试仍有 1 项 BOX 标签断言失败，不记作全部通过。
- `reference-code/result.json`：直接加载参考目录着色器的 98 组滤波对照无差异。参考实现另有 16 组覆盖范围外的材质连续性检查不符合完整包要求，因此该次测试总退出码为 1；它不是完整包的回归失败，也不能被记作参考代码全部测试通过。

`reference-source/` 使用现有原版投影测试程序加载参考目录着色器，属于阴影路径对照，不是重新构建整个参考工程。`real-pair/` 另存真正的 9.32 程序与现有 MMS 的同设置图片。`real-pair/perspective/` 中的空白导出为无效诊断，不用于画质结论。供用户确认的局部对照图位于 `preview-for-review/`，每幅图均保留原像素比例。

## 画质边界

恢复滤波不等于完整包的最终阴影与 9.32 逐像素相同。当覆盖无需扩展时，完整包保留原版投影；需要防裁切时，同一滑块值下的贴图分布仍可能与旧版不同。低精度下仍可见锯齿或波浪状轮廓，极低精度会丢失细投影。外部特效自己的过滤算法和固定贴图尺寸也不由本次改动替换。

测试只操作独立进程，没有关闭用户已开启的 MMD。部署文件与 SHA-256 记录在同一证据目录的 `approved-deployment.json`。
