# Stage.pmm 的 MME 预览缩放与阴影范围优化

本轮使用用户指定的 `Stage.pmm` 复现。MME 中随屏幕大小变化的渲染目标已经跟随预览比例缩小；部分固定尺寸目标和每帧模型处理仍保持原来的工作量。降低预览比例不能消除这些开销。

阴影覆盖范围的全顶点计算已改为 SSE2 批量比较。本机短时 ABBA 对照中，这部分耗时降低约 49%～50%，整帧吞吐提高约 9%～13%。该结果来自固定第 0 帧的重复绘制，不是动画播放帧率，也不代表所有工程的提升幅度。

## 场景与尺寸观察

- 工程：`D:/MMD-Next/tests/ToonGlass_Ray/UserFile/Stage.pmm`，使用配套 EMM 和真实 MME DLL。
- 显卡：NVIDIA GeForce RTX 4070 Laptop GPU。
- 加载的 11 个模型保持独立所有权；测试前后 PMM 和 EMM 的 SHA-256 一致。
- 最终构建在原生 D3D9 绘制入口记录目标纹理和视口尺寸。记录过程位于计时区间之外。

| 目标类型 | 100% 预览 | 25% 预览 |
| --- | --- | --- |
| 随屏幕大小变化的主要 MME 目标 | 725 × 406 | 181 × 102 |
| 部分后处理缩小目标 | 362 × 203 | 90 × 51 |
| 观察到的固定目标 | 2048²、1024²、512²、256² 等 | 保持不变 |
| 应用持有的原生阴影纹理 | 8192² | 2048² |

原生阴影纹理尺寸来自资源查询，不等同于 MME 当前绘制到的目标尺寸。此场景在两种预览比例下，都有 137 次绘制落在同一规格的 2048² 目标上。尺寸跟踪按格式与大小分组，不提供特效资源名称，因此不能仅凭此记录断言该目标属于某个具体特效。

本轮没有强行缩小特效声明的固定尺寸资源。这类资源可能承载阴影、查找表或跨帧数据，统一缩放需要另行确认其用途。阶段计时还显示，模型变形与蒙皮、材质提交等 CPU 工作不会随像素数量同比减少。

## 修改内容

`NativeShadowVertexBounds` 在已锁定的顶点缓冲区上同时比较 XYZ 范围，仍读取所有顶点。遇到非有限坐标时跳过整个顶点；相等值保留先前位模式，包括正负零。12 字节顶点步长及不支持 SSE2 的构建使用原有标量规则。

这项改动不依赖 NVIDIA 接口；x64 的 Intel、AMD CPU 都可使用 SSE2 路径。本轮没有 AMD 实机性能数据。

诊断计时新增阴影范围计算及缓冲区锁定两个阶段。正式构建关闭 `MIKUDANCESTUDIO_PERF` 和 `MIKUDANCESTUDIO_DIAG`。

## ABBA 对照

顺序为旧版、新版、新版、旧版。两种二进制使用相同测试宿主、设置和诊断计时；差异为原始标量范围扫描与 SSE2 范围扫描。基线建立在 `bd7ff2e` 的渲染实现上。

每轮按 100%、25%、25%、100% 顺序运行；每段预热 0.5 秒，测量至少 1.5 秒，在区间边界等待 GPU 完成。固定第 0 帧，关闭物理，使用 MMD 原始抗锯齿、固定阴影策略和未增强阴影滤波。吞吐按各段总帧数除以总耗时合并。

| 预览比例 | 旧版帧/秒 | 新版帧/秒 | 吞吐提升 | 旧版范围计算 | 新版范围计算 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 100% | 43.68 | 47.72 | 9.25% | 3.743 ms/帧 | 1.922 ms/帧 |
| 25% | 43.37 | 49.01 | 13.01% | 3.784 ms/帧 | 1.878 ms/帧 |

这些短样本用于确认本次改动有收益，仍会受到调度和设备负载影响。最终关闭插桩后的尺寸检查仅作为功能验证，不与上表混用。各轮数据及二进制校验值见 [对照记录](MME_PREVIEW_PERFORMANCE_20261015.json)。

早期测试发现，测试宿主把模型 0 的指针赋给了当前选中槽位，导致多模型 PMM 重复持有同一模型，退出时重复释放。现已改为选择槽位 0，并检查所有已加载槽位的指针互不重复。上表四轮均使用修正后的宿主，均正常退出；早期异常样本未纳入统计。

## SMAA 菜单与验证

- SMAA 二级入口只展开子菜单，没有默认档位，也不再通过点击或 Enter 恢复上次所选。
- 选中 MSAA、FXAA 或 TAA 时，SMAA 二级及三级项目均不显示选择圆点。
- 选中 SMAA 时，二级入口和三级当前档位同时显示圆点。
- 中、英、日 README 已同步。
- 最终原生及真实 MME 抗锯齿回归分别通过 854 项，包含三种界面的菜单状态和时间抗锯齿检查。
- 预览缩放规则通过 411 项；顶点范围通过 144 组与标量实现的逐位比较，并通过既有投影覆盖检查。
- 最终 Stage 尺寸跟踪正常退出，PMM、EMM 未改变。
