# 五档透明排序上限

> 本文保留首次五档调整的实现与测量记录。其后三个中低档已再次下调，当前语义见[三档强度下调](TRANSPARENT_SORT_STRENGTHS_20260927.md)。本文性能数据仅适用于当时的版本。

2026-09-27 按用户要求重排透明排序档位，删除「极高」及「低」后的括号。实现提交为 `1e54b05`，基线生产源码为 `988d7f8`。默认「标准」改用此前「低」的排序方式，因此新建工程和无排序字段的 PMM 不再默认执行逐像素分层。

## 档位与绘制方式

「显示 → 透明排序上限」按以下顺序显示。关闭仍是独立档位，选择关闭不记忆先前精度。

| 选项 | 存档字节 | 行为 |
| --- | ---: | --- |
| 关闭 | 4 | 不执行自动透明排序。 |
| 低 | 0 | 用 64 个深度桶从远到近排列透明三角形，同桶保留输入顺序。 |
| 标准（默认） | 1 | 原「低」的逐三角形中心深度排序；同深度按原始三角形序号。 |
| 高 | 2 | 原「标准」的 1024 次分层迭代上限。 |
| 最高 | 3 | 仍以参与排序且裁剪后的三角形数量加一为迭代上限，完成后提前结束。 |

原高档 2048 次与极高档 4096 次的中间上限不再提供。低和标准不分割几何、不做逐像素分层，所有有效输入面仍完整绘制。新低档降低排序粒度和绘制提交开销，不删除模型面数；同桶内允许深度逆序，因此排序质量低于标准。

高和最高沿用原分层合成及不透明遮挡处理。分层未完成时丢弃中间结果，再回退完整几何。自定义效果或不支持分层的设备仍有近似排序限制；高档 BSP 回退预算为额外 250000 个三角形、深度 128、epsilon 1e-11，最高档为额外 4000000 个三角形、深度 512、epsilon 2e-13。配件独立通道和 MSAA 部分覆盖边界未扩大支持范围。

## PMM v2 保存

使用 `org.mikudancestudio.view.transparent_sort_precision` 的单字节字段直接保存上表数值。用户明确说明此前版本只用于测试，要求不处理兼容映射，因此不识别或换算旧测试版的档位；相同字节直接按新语义解释。旧开关标识仅作为普通未知记录保留，不影响档位。

无字段、新建工程与无效扩展使用标准。未知或不合法的精度字节也以标准运行，在用户明确选择档位前保留原始数据。关闭只写入字节 4，不保存此前档位。运算器、骨骼缩放及其他扩展记录保持独立。具体布局见 [PMM v2 扩展格式](PMM_V2_EXTENSIONS.md)。

15 次独立运行全部通过：新版几何与扩展 codec、带真实 ToonCloud PMX 的 PMM 保存/重开/另存，以及前后各六项低 alpha、低 alpha + 4x MSAA、相交面 + 4x MSAA、预算耗尽回退、最高档、最高档 + 4x MSAA。两侧像素驱动源码相同，显式选择等价档位，不依赖重排后的默认值。

几何测试验证跨 draw 的远近顺序、同桶稳定性、每个有效面及顶点属性恰好保留一次、零跨度与非法输入。真实云诊断中低档与标准均输入/输出 21412 个三角形，不产生分割；低档实际使用 61 个非空桶。高档实际完成 668 层，日志为 `complete=1 committed=1`。最高档专项仍完整完成 1152 和 4608 层，单采样及 4x MSAA 均符合像素解析式。

没有重跑全量 CTest。历史自阴影 alpha 的 8 个既存失败点、96×96 深层压力未完成样本及第三方效果覆盖边界保持原记录，不计为本次通过。

## 双 build 云场景对照

原云 PMM/PMX/Toon 未修改，MME 加载、Cloud.fx 关闭、ikParticle.fx 保留。两个独立生产核心链接同一基准驱动，运行库和配置一致；1076×606 视口、8x MSAA，每次预热 2 帧后测量 5 帧。每组均按前/后/后/前运行，合计 20 次。

| 对照目的 | 前版批次 ms/帧 | 新版批次 ms/帧 | 图像结果 |
| --- | --- | --- | --- |
| 原低 → 新标准 | 91.077–101.630 | 96.400–97.298 | 最多 12 个像素差 1/255；基线自身两轮也有 25 个像素差 1/255。 |
| 原标准 → 新高 | 571.139–606.768 | 583.234–610.027 | RGBA 逐像素一致。 |
| 原最高 → 新最高 | 572.283–578.006 | 570.459–598.765 | RGBA 逐像素一致。 |
| 原低 → 新低 | 97.483–99.050 | 15.435–18.889 | 有明显画面差异，属于降低排序精度。 |
| 原默认 → 新默认 | 575.538–578.942 | 100.182–103.022 | 新默认沿用原低档，属于质量与性能取舍。 |

这些是等待 GPU 完成后的批次耗时，不是桌面播放 FPS。等价档的耗时差异处于轮次波动范围，不能声称等画质加速。低档和默认档的减耗来自精度选择改变；密集云团需要原精细效果时使用「高」或「最高」。

独立路径诊断不纳入计时样本。第一次诊断将 `--warmup` 设为 0，工具以参数错误退出；失败日志保留在 `trace/`，修正为 1 后的有效诊断在 `trace-valid/`。
