# 网格导出与烘焙

**烘焙 → 烘焙网格…** 默认只写入工程缓存；**烘焙 → 导出 ABC…** 默认只导出文件。两项也可同时勾选。停止播放、录制后操作。取消采样不会提交半段缓存；同时输出时，若文件成功而工程提交失败，会分别报告。

有 MMV 层列表时，「烘焙方式」默认是「范围缓存」，保留 FX 赋予并按区间记录启停键。只有主动选择 MMV 层时才永久删除相应层及更高层 FX，并检查完整帧范围和对象覆盖；安装 MMV 本身不会触发这些删除警告。见[警告逻辑验收](../records/animation/baking.md#record-bake-warning-logic)。

## 选择来源与输出范围

列表包含所有已加载的模型和 `.x` 附件，不按 FX 名称或已知物理后端过滤。勾选要输出的对象，再为各对象填写材质和顶点编号；编号从 0 开始，支持 `0,2,5-10`，留空表示全部。模型还可选「仅已选骨骼的权重顶点」。各过滤条件取交集。控制器没有可见几何时仍可参与 FX 开关键帧的记录。

完整对象可缓存可变拓扑。局部顶点缓存按源顶点编号覆盖，只改所选顶点的位置和法线，其他顶点继续使用当帧 MMS 动画。局部模式保留源拓扑；没有源编号的生成顶点不能局部烘焙，应选择完整对象。纯 ABC 输出不支持局部顶点过滤，界面会要求启用工程烘焙。

帧号使用程序支持的非负整数范围，按 MMD 的 30 fps 时间轴解释；超出范围时拒绝操作。采样率为 1–120，默认 30；从第 0 帧预计算，在指定区间内输出。场景在副本中求值，结束后恢复编辑器状态。物理采用独立世界，不保证与所有实时物理后端逐位一致。

## 工程缓存与 FX 开关

新工程缓存采样 **MMS/MMV 交接处、MME 着色之前** 的几何，MME 继续着色。MMV 插件物理（包括 Bullet3）以最终网格变化烘焙；原生 Bullet 骨骼姿态通过「关键帧烘焙」输出。当前 MMV 网格 ABI 没有反向写回骨骼姿态的接口。

- 所选来源的 MMV 效果实例写入原生「启用」轨道：起始帧 `0`、结束后一帧恢复此前该时刻的值，使用常值 Step；范围内旧启停键被替换，范围外保留。开关可在参数面板编辑。
- 新缓存只在 `[起始帧, 结束帧+1)` 生效，范围外恢复 MMS/MMV 当帧求值；缓存样本之间保持前一样本。
- 全对象缓存不再跟随区间内原骨骼、表情或附件变换；局部缓存只冻结所选顶点。源模型和动画记录保留。
- MME 分配在创建代理、重开 PMM 和清除缓存时迁移恢复，不为新缓存停用纯着色效果。
- MMV DLL 须支持区间烘焙接口；版本不匹配时拒绝提交，保留旧配置。没有安装 MMV 时，原生 MMS 网格仍可烘焙。
- 原生启停轨道属于实例；关闭一个控制整个场景的物理 FX 会影响该实例负责的全局模拟，不能把它理解为独立关闭某个刚体。

PMM 记录相对路径映射，几何另存为旁边的 `<工程名>.<内容标识>.mdsmesh.abc`；VMM 保存 FX 开关键帧。移动工程时一起保留 PMM、EMM、VMM、缓存及源素材。VEM 仍为手动保存/载入的静态预设。原版 MMD 忽略本工程的缓存扩展。

旧版没有区间标记的缓存仍按旧规则读取（范围外保持端点，停用已包含的 MME/MMV 变形），避免旧工程被再次变形。新规则不追溯改写旧存档。

## 清除缓存

「烘焙 → 清除网格烧录…」可选择当前模型或全部对象；网格窗口的清除按钮只清除列表勾选的对象。清除恢复源动画，保留 FX 启停关键帧，用户可在参数面板修改这些键。清除不删除已保存的缓存文件；保存 PMM 后写入新状态。网格缓存不占骨骼撤销栈。

## ABC 文件

仅导出 ABC 时仍捕获实际 DX9/MME 顶点着色器后的网格，适合向其他软件交付最终几何；不改变工程分配。同时选择工程缓存时，两种输出共享 MME 前的原生几何。ABC 使用 Ogawa，右手系 Y 向上、Z 相对 MMD 反向，UV 的 V 翻转；单位沿用 MMD。原生捕获保留顶点法线，传统绘制捕获重算法线。每个对象、材质和绘制通道保存为 PolyMesh，可变拓扑和消失组使用独立样本。

传统捕获支持标准索引三角形、VS 1.1/2.0/3.0；不支持的着色器重放或绘制方式明确报错。纹理像素、后期、阴影图与描边不作为导出内容。ABC 不含骨骼、动画曲线或 FX；相机相关变形已固定在采样镜头下。
