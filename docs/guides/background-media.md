# 背景媒体移动与缩放

图片与视频使用同一组视口按钮。最小包的视频背景限于原版 AVI 路径，完整包还支持 MP4、MOV。

## 操作

| 视口右上角操作 | 效果 |
| --- | --- |
| 按住 Ctrl，按住十字箭头并拖动 | 按鼠标方向移动背景 |
| 按住 Ctrl，按住放大镜并上下拖动 | 向上放大、向下缩小，保持背景中心位置 |
| 不按 Ctrl，拖动这两个按钮 | 保留原有相机操作 |

图片与视频共用以上操作。两者同时显示时，视频位于上层，拖动调整视频；隐藏视频后调整图片。没有可见背景时，Ctrl 拖动不改变相机。

操作对象在按下鼠标时确定，直到松开鼠标或取消捕获才结束。中途松开 Ctrl 不切换操作对象。拖动到视口边缘仍可继续，结束后恢复光标。缩放范围为原始尺寸的 0.001 至 100 倍。

背景位置与缩放比例随 PMM 保存。解码兼容性与验证范围见[背景媒体记录](../records/rendering/background-media.md)。
