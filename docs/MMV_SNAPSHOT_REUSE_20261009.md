# MMV 场景快照复制修复（2026-10-09）

MMS 在渲染前通过已有 `queryInputDemand` 接口查询插件所需输入。查询阶段保留对象身份、材质、骨骼、Morph 和物理结构的元数据；随后按返回的需求复制完整场景。原始顶点、权重和物理结构只有在需要时才读取。接口缺失或查询失败时仍复制全部数据。

宿主渲染所需的当前顶点、三角形、材质、骨骼和 Morph 始终存在。未请求原始顶点时，当前顶点流仍保留 PMX 描边倍率和 PMD 描边禁用标记。

对于已经采用 `XYZ | NORMAL | TEX1` 布局的附件，宿主直接读取其当前顶点和索引缓冲，并复制到自己的快照。其他布局仍通过 D3DX 转换。此改动避免先克隆整个附件网格再读取，不向宿主模型写回数据。

本轮配合 MMV4MMS 的输入需求、网格和反馈纹理复用修改。在相同 Stage 工程的两次实际播放对照中，修改前为 2.759、2.799 FPS，修改后为 5.366、5.550 FPS。该数字是组合改动结果，不能归因于此宿主补丁单独产生。原生 MME 为 41.739、40.835 FPS，卡顿仍未完成修复。

已构建生产核心，并以分别链接修改前后生产核心的后台工具运行相同 PMM、EMM、物理和相机条件。未替换用户安装的 EXE 或 DLL，也未重启用户程序。插件兼容检查、共享目标及设备重置检查通过。完整结果见 `D:/MMD-Next/MMV4MMS/docs/RAY_FULLSCREEN_REPAIR_20261009.md`，证据及逐次二进制哈希在 `D:/MMD-Next/MMS/.local/artifacts/ray-acceptance-20261009/`。
