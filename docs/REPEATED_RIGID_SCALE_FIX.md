# 重复父骨骼缩放造成刚体形变

## 修复

物理读回产生的局部补偿矩阵曾再次参与碰撞形状计算。父骨骼缩放与刚体旋转交替发生时，补偿逐次进入尺寸计算，造成刚体尺寸漂移。

碰撞形状现在使用创建物理状态时记录的骨骼基准，以及用户修改的缩放值。物理读回补偿继续用于姿态显示，但不进入下一次碰撞形状计算。
