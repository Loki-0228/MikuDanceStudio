## 外置描述与算法源码

作者文件为 FX 语法，不使用先前试验的 `ui { ... }` 文本格式。内部 `ParseLayout` 保留用于数据路径测试；公开帮助、示例和文件加载均使用 FX 变量声明与注解。

`parameter_metadata.inl` 在相同预处理流程中读取描述文件，核对原变量的名称、类型与可写性，再生成 `Schema`。原 DX9 FX 源文本保持不变。原生 DX12 参数仅在内存编译副本中改为自动 b1 常量块，写盘测试验证原文件未变化。

外置描述的默认扩展名由 `.mmvui` 改为 `.uifx`，改动在 `parameter_metadata.inl` 的 `layout.replace_extension` 一处。默认查找只做 `Face.fx` → `Face.uifx`，`.uifx` 缺失时不会回退到同名 `.mmvui`，也不把该文件计入热重载来源；随包 6 个描述文件已改名为 `.uifx`，三个透视样例的 `#include` 同步指向 `perspective_controls.uifx`。`MMVConfig` 的 `string MMVUI="..."` 显式路径仍按写下的后缀读取，加载器不附加也不校验后缀，旧文件可以由显式路径继续指到，因此旧同名文件需要改名，而不是靠回退兼容。`MMVUI`、`MMVUIGroup_*` 注解名，以及 `.vmm/.vem` 参数轨道、稳定 ID、关键帧、多语言、面板布局与热重载语义均未改变。

## 验证产物

早期参数模块产物保留在 `.local/artifacts/mmv-parameters/`：

- `core/`：DSH 的编译、三轮复核、失败和修复日志、源码及 EXE 哈希。
- `effect-01/`：旧试验布局与数组注解识别失败的原始样本。
- `effect-02/` 至 `effect-05/`：外置 FX 描述的迭代样本；最终 `effect-05/` 为 46 项检查。
- `existing-fx-02/`：599 项已有效果解析回归的输入文件。
- `gpu-01/`：测试快照缺少对应权重数组，被生产校验拒绝；保留失败样本。
- `gpu-02/`：修正测试输入后 71 项通过，包含逐帧计算与回读耗时 CSV。
- `plugin-compare-01/`：同一测试 EXE 与相同 FX/描述文件。旧生产 DLL 在第 15 帧的参数采样检查失败；新版 DX12 和兼容版各 118 项通过。保留两侧 DLL、EXE 哈希、输入和逐帧顶点输出。
- `editor/`：面板的失败样本与修复记录。早期模态测试因跨线程等待挂起，已改为同一 UI 线程并设置有界运行；测试进程身份及失败日志保留。最终 `run-final.log` 为 8,688 项通过。
- `editor-independent-02/`：主 agent 从最终源码独立构建并执行，同样 8,688 项通过。窗口保持隐藏；打印图用于排版定位，隐藏 EDIT 文本和下拉展开内容不由 `WM_PRINT` 完整显示。控件值、文字宽度、键盘、裁剪和提交行为另有实际消息及几何断言。
- `gui-example-gpu-01/`：初稿的对象分配没有应用颜色，GPU 检查拒绝该结果，保留失败日志。最终示例统一对象/材质颜色筛选，并让禁用开关同时关闭几何与颜色操作。
- `gui-example-gpu-02/`：修复后的 180 项 GPU 检查；`gui-example-compile-02.log` 为 14 个 FX 编译通过记录。

扩展名变更的产物另存于 `.local/artifacts/mmv-uifx/`。`before/` 是旧源码及基线结果，`final/` 是最终源码的构建与运行记录：3,148 项参数检查、68 项前端检查和 14 个示例编译通过。`mutation/` 使用旧解析器编译同一份新测试，在描述文件发现检查上失败；主 agent 已核对旧解析器与 Git 基线一致。`probe/` 确认六个示例实际加载了 `.uifx`，另有一个共享的 `perspective_controls.uifx` 被透视示例包含。测试初稿误比对被测试自身改写的 FX，其失败输出保留在 `dsh-events-91.log`，最终删除重复断言后通过；原有的源 FX 字节不变检查仍保留。
