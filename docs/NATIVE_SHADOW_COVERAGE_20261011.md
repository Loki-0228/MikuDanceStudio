# 原生自阴影、动态精度和主题修复

状态：本地验证通过，发布等待其他修复完成。

用户报告开启自阴影后球面中部漏影、阴影边界随视角流动，关闭 MME 后仍然存在；取消动态缩放后只剩材质明暗。用户指定的「洛希极限」模型用于生产渲染复现。最初的球体测试没有投射实际阴影，只验证了材质明暗，未能覆盖这一问题。

## 投影与材质

旧投影在相机旋转后的坐标中构造光源矩阵，再施加与视角有关的透视扭曲和纵向偏移。视点目标落在阴影贴图边缘，导致模型部分区域被裁切；旋转相机时裁切位置也发生变化。复现时，模型只占据阴影贴图底部的局部区域。

现在按场景坐标中的光源方向生成正交投影，以当前观察目标为中心。相机旋转不再改变投影矩阵和深度贴图。阴影范围仍由滑条控制，模式 1、2 分别使用原有常用横向尺度的 2 倍、3 倍系数，并保留各自的深度比较容差。此处替换了旧的视角相关扭曲，不能视作完全保持旧投影外观；没有引入全场景自动包围盒拟合。

PMX 投影材质也有两处错误：描边宽度为零时整块材质被跳过；是否双面投影读取了实际上保存「描边启用」的旧字段。现在投影取决于材质的投影标志，双面剔除取决于真实双面标志，均与描边开关、宽度独立。

SM3 和 SM2 材质着色器此前在坐标越界时直接返回亮色和高光，跳过 toon 明暗及暗部高光遮罩。现在越界只取消阴影采样，保留材质明暗。SM3 在覆盖判断前求导；SM2 使用紧凑范围判断及等价混色，满足 `ps_2_0` 指令上限。

## 动态精度与主题

动态精度滑条改成与固定阴影范围相同的方向：数值越小，精度越高。动态模式仍只调整贴图分辨率，不改变阴影范围或光源。取消勾选后恢复固定分辨率和原阴影范围。

「动态缩放」复选框接入既有面板复选框绘制，背景按实际位置绘制自阴影分区渐变，文字跟随同区浅色标签；保留勾选、悬停、禁用和键盘焦点处理。

## 验证

- 「洛希极限」原始模型，无 MME，960 × 720 视口，两种模式、2048 和 4096 两种贴图尺寸、0°／45°／90° 三个视角，共 12 组。通过临时禁用投影而保留 toon 和材质参数，确认画面确有遮挡阴影。
- 每种模式及固定分辨率下，三个视角的完整阴影贴图 SHA-256 相同。动态低精度、高精度再取消勾选后，阴影范围不变，恢复的深度贴图与原贴图逐位相同。真实模型的多重采样与透明三角形交界允许少量像素波动，测试上限为画面像素的 0.1%，不以最终画面逐像素相同作为验收结论。
- 新增 `native_shadow_cycle` 生产回归，使用原创无描边、描边宽度为零的双面投影者和接收面。两种模式、三个视角全部通过；取消投影标志后遮挡消失，恢复后遮挡重现；精度值 9999 分配 1024 贴图，精度值 0 分配 2048 贴图。转动视角及取消动态缩放后的贴图一致性通过。
- `native_shadow_tests` 验证观察目标和周围物体覆盖、极轴光源、同一光线上的投影者与接收者坐标关系，以及原有斜面、薄阴影、模式容差、滤波和透明度检查。
- SM3、SM2 的 28 组材质覆盖边界测试通过。隐藏窗口五组主题、控件切换、启动和 1080p 录制回归通过。
- Release 主程序构建成功；四项相关 CTest 全部通过。

仓库测试为 `native_shadow_tests`、`native_shadow_sm2_coverage`、`native_shadow_cycle` 和 `display_compatibility_regressions`。本机命令、截图、日志、模型与程序哈希保存在 `.local/artifacts/shadow-theme-20261011/`，隔离构建位于 `.local/builds/shadow-theme-20261011/`。用户模型及纹理不纳入仓库。

本次验证覆盖原生渲染和指定模型，未验证第三方 MME 效果。发布仍需等待其他修复完成。
