# 测试与验收

按改动涉及的功能选择测试目标。完整清单、构建选项和运行器用法以 [tests/README.md](../../tests/README.md) 为准。

1. 确认构建档、编译配置与所需测试开关。
2. 显式构建相关测试目标。部分测试使用 `EXCLUDE_FROM_ALL`，普通构建不会生成它们。
3. 使用测试说明中的运行器或 CTest 名称执行检查。
4. 保存命令、退出码、日志和实际测试程序的哈希。

可先列出当前构建配置已登记的测试：

```powershell
ctest --test-dir build -C Release -N
```

`full` 与 `mmd932` 的功能范围不同。共同实现的改动分别验证两档；最小包不包含的功能不能直接套用完整包测试结论。MME 检查还须确认实际载入的 DLL、效果分配和输出画面。

性能测量与正确性测试分别记录。后台或隐藏窗口运行仍需完成正常渲染工作，不能把最小化节流算作提速。方法见[帧基准](benchmarks.md)，结果查阅[专题记录](../records/README.md)。

原版行为的静态核验见[原版二进制核验记录](../records/development/reference-audit.md)。其中的地址、哈希和临时探针只适用于注明的版本，不作为通用运行命令。
