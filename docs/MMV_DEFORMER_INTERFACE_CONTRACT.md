# MMV 骨骼、刚体与 joint 循环输入输出接口标准

日期：2026-09-27。状态：公共 ABI、层循环、结构快照和 GPU 只读输入已实现于正式 `main` 工作目录；完整交付仍按测试记录逐项验收。

接口规范已并入 [MMV FX 总接口](MMV_FX.md#原生结构与状态循环)，准确二进制字段以
[mmv_deformer.h](../include/mmv/mmv_deformer.h) 为准。本文保留原设计约束与验收清单，
实际执行结果见 [实现记录](MMV_IMPLEMENTATION.md)。算法 DLL 的可用性与算法验证单独记录。

## 会话分工与基线

接口会话负责公共头文件、层调度、结构合并、数据生命周期、查看窗口、FX 接入、存档关联和接口测试。本会话负责 DDM 重蒙皮、AVBD 细分刚体、SDS 辅助骨骼、0 层网格物理的算法模块与 `.x` 案例。

正式仓库为 `D:/MMD-Next/MikuDanceStudio-MME`，集成分支为 `main`。
早期分层代码来自 `.local/worktrees/mmv-bone-physics`；该工作树保留作为来源证据，
后续循环接口以正式目录为准，不将旧工作树二进制视为当前部署版本。

宿主类型位于 `include/mmv/mmv.h`。`MmvObjectOutput` 保持原有网格交接布局。
`mmv_deformer.h` 负责内部完整结构输出与快照查询；`physicsInput` 提供当前表情后的
蒙皮前顶点和物理绑定信息。HLSL 新增结构只读 SRV，仍只有网格和材质输出 UAV。

本标准保持现有层级、`.x` 的 `MMVAccessory` 声明和 `.vemN`、VMM 规则。正层从高到低执行，MMV 固定为 0 层，MME 固定为 -1 层。附件不声明层号。

## 循环与数据可见性

「循环输入输出」包含同帧的逐层传递和跨模拟步的状态反馈，不允许通过循环依赖图反复执行效果。

| 输入通道 | 含义 | 可修改性 |
| --- | --- | --- |
| `Source` | 当前宿主原始定义、动画驱动、绑定数据及表情后的蒙皮前几何 | 只读，不能包含上次 MMV 输出的重复变形 |
| `Upstream` | 当前层开始时冻结的完整场景状态，含上层新增结构 | 只读，同层所有效果读取同一版本 |
| `PreviousCommitted` | 当前求解实例最近一次成功提交的状态和输出 | 只读，首步及重置后无效 |
| `Candidate` | 本次计算的候选结构、网格和下一步内部状态 | 仅生产者拥有，不向同层其他效果公开 |

运行时只在完整校验和合并成功后发布 `Candidate`。下一层读取本层发布结果。下一模拟步同时读取新的动画输入和本实例历史状态，不能仅把最终渲染网格重新送入蒙皮。

同层效果不得读取彼此尚未提交的输出。跨模型碰撞在同一个求解域内一次计算。域内多个对象、刚体组和跨组 joint 共享一次状态提交。不同原生求解器对同一动态刚体的同时接管必须报错，不能靠显示顺序分别推进后再混合物理结果。

算法内部的迭代和子步由一次 `evaluate` 调用完成，不递归调用 MMV 层调度。

## 原生计算模块接口

新增独立头文件 `include/mmv/mmv_deformer.h`，版本宏为 `MMV_DEFORMER_ABI_VERSION=1`。计算 DLL 导出 `MMVDeformerGetApi`。此版本独立于现有宿主 `MMV_ABI_VERSION`。

接口采用 C ABI、定长整数和结构体大小字段。跨 DLL 不传 STL、DirectX、Bullet 对象或 C++ 异常。现有宿主最终网格交接保持原布局，新增层结构由 MMV 内部持有。若需给旧宿主结构增加服务，只在可选尾部追加，并检查 `structureSize` 和能力位。禁止改变既有数组元素的步长而继续沿用旧 ABI。

| 接口 | 契约 |
| --- | --- |
| `getCapabilities` | 声明读取通道、写入通道、支持形状、有状态标志、支持范围及是否仅允许 0 层 |
| `create` | 根据稳定效果实例和求解域配置创建实例，不推进模拟 |
| `evaluate` | 接收 `MmvDeformerInput`，返回候选句柄和 `MmvDeformerOutput`，失败不得改变已提交状态 |
| `commit` | 将已校验候选切换为内部已提交状态，并释放候选。该操作不得分配资源或失败 |
| `discard` | 丢弃候选及其暂存状态，不改变已提交状态 |
| `reset` | 接收明确的重置原因，清除历史状态，从下一份有效输入重新初始化 |
| `destroy` | 释放实例及所有候选资源 |

`evaluate` 内完成预处理缓存更新、子步和输出构建。首次调用、结构版本变化或缓存缺失时才重建预处理。计算统计分别记录预处理与推进耗时。

同一实例串行调用。输入指针只在 `evaluate` 调用期间有效。输出数组与字符串由候选持有，直到 `commit` 或 `discard`。运行时必须在结束候选前将成功输出复制或显式接管到自己持有的快照。输入与输出不得别名。

实例内部可保存任意算法状态，例如速度、乘子和接触缓存，但不能保存宿主借用数组的裸指针。查看窗口只能读运行时持有的快照。

## 输入与输出字段

`MmvDeformerInput` 至少包含以下信息。公开头文件必须确定准确字段、类型、所有权和默认值，算法会话以该头文件为唯一二进制契约。

| 字段组 | 必需内容 |
| --- | --- |
| 版本与身份 | `structureSize`、接口版本、能力、效果实例键、求解域键、层号、对象标识和对象 `generation` |
| 请求与时间 | `evaluationId`、`inputRevision`、`stateEpoch`、起始 `simulationTick`、固定步长、待推进步数、当前时间、播放及编辑状态 |
| 三类输入 | `Source`、`Upstream` 和可选 `PreviousCommitted` 视图，及其有效标志 |
| 配置 | 本次采样后的参数块、配置版本、必须重置的参数变化标志、选中的对象和骨骼范围 |

`MmvDeformerOutput` 包含候选句柄、读写范围、完整候选对象表、结构版本、网格版本、处理统计和结构化诊断。不写入的通道继承输入，不能用空指针同时表示「不变」和「清空」。每个输出通道使用 `Preserve`、`Replace` 或 `Clear` 明确表达。

完整对象记录由已有数据结构及平行扩展表组成：

| 数据 | 输出要求 |
| --- | --- |
| 网格和材质 | 沿用 `MmvMesh`、材质身份和 `sourceVertex` 语义，支持现有拓扑输出 |
| 骨骼 | 当前世界姿态、绑定变换及其逆、父级、有效标志、稳定键、来源键和名称 |
| 权重 | 与该层绑定顶点表对应，指向该层骨骼，首版最多四项非零影响，权重非负并归一化 |
| 绑定几何 | 不变的宿主来源表，以及当前层可扩展的绑定顶点表和表情后蒙皮前位置、法线 |
| 刚体 | 稳定键、绑定骨骼、运动模式、形状引用、世界姿态、速度、质量、惯量、阻尼、摩擦、恢复系数、碰撞组及掩码 |
| joint | 稳定键、A/B 刚体引用、两端局部连接框架、线性和角度限位、弹簧与阻尼、关联碰撞设置、有效标志 |
| 碰撞形状 | 球、盒、胶囊及新增凸网格、复合形状资源，含顶点、索引、子形状局部变换和版本 |
| 来源关联 | 新项对应的原骨骼、刚体、joint 或顶点来源，及当前层到宿主原始顶点的映射 |

现有 `MmvWeight` 的四项权重限制保持不变。DDM 的矩阵权重、压缩系数和其他算法专用缓存属于求解实例资源，不伪装成 PMX 权重。需要传递的辅助骨骼通过扩展骨骼表和常规权重表达，截断造成的误差由算法模块报告。

宿主来源编号与当前层顶点编号必须分开。生成顶点没有唯一宿主来源时仍用 `0xffffffffu`，其新骨骼权重通过当前层绑定记录传递。运行时不能以该标记为由丢弃合法的层内权重，也不能用新骨骼索引访问宿主原始表。

### 稳定身份与结构修改

原项身份以对象稳定键、类型及源项标识为基础。新增项的规范键由生产效果实例键、类型和算法局部键组成。名称和数组索引不是身份。内部可使用数值句柄加速，但必须检查键冲突并保留稳定键。

同一结构版本内，新增项身份跨帧保持不变。仅更新姿态和速度不递增结构版本。增加、删除或重绑定骨骼、刚体、joint、权重及碰撞形状时递增结构版本，并使依赖这些结构的缓存失效。

输出支持数量增加、数量减少、重排和引用重映射。删除有引用的项必须同时修复父级、权重、刚体绑定和 joint 两端，否则整项提交失败。不得自动将失效引用改成第 0 项。

普通 joint 的稠密索引仍属于当前对象。跨对象连接使用新增的显式 `(objectKey, rigidKey)` 引用表，不把另一对象索引塞入旧 `rigidA` 或 `rigidB`。首版运行时能够校验并传递该引用；具体求解器通过能力位声明是否能求解。

### 坐标与 joint 同步

矩阵保持现有行主序、行向量约定。网格在对象空间，骨骼及刚体姿态在 MMD 世界空间。骨骼记录区分绑定矩阵、当前世界矩阵和蒙皮矩阵，不能互相替用。

刚体姿态以质心为原点。碰撞顶点和子形状变换定义在刚体局部空间。绑定偏移必须明确转换方向，不根据字段名猜测。

扩展刚体记录提供质心局部空间的对称 3×3 惯量张量。只接受三个主惯量的后端由适配器执行主轴分解，并同步形状、绑定和 joint 局部框架。动态刚体要求质量为正且惯量正定，静态或运动学刚体允许质量为零。

joint 的局部连接框架是约束定义，世界连接框架是当前帧派生数据。使用 `anchorA = frameA * bodyWorldA` 和 `anchorB = frameB * bodyWorldB` 更新。刚体姿态、质心或 joint 端点变化时，必须在发布快照前同步对应数据。

线性与角度限位按每轴保留原生 Bullet 语义：`lower > upper` 表示自由轴，`lower == upper` 表示锁定，`lower < upper` 表示区间限位。快照导入和 FX 输出均保留原值，不因上下限倒置而拒绝关节，也不排序或夹紧限位。NaN、无穷值及非法刚体引用仍拒绝提交。

不能只传递新的 `rigids`，却继续将旧宿主 `joints` 指针挂在下一层输入上。`valid=0` 明确表示不可求解，不能把全零矩阵当作有效姿态。

## 跨帧状态与原子提交

| 标识 | 行为 |
| --- | --- |
| `evaluationId` | 区分一次求值请求，不等于时间轴帧号 |
| `inputRevision` | 区分同一时间轴帧内的动画编辑或参数修改 |
| `stateEpoch` | 在重置或不连续恢复后改变，阻止复用旧历史状态 |
| `simulationTick` | 按实际固定子步单调递增，同一步重复查询不再次推进 |

成功候选、层输出和求解器状态属于同一提交事务。运行时先验证候选、选择实际生效范围，再为所有受影响对象构建可发布快照。任何一步失败都调用 `discard`。全部准备成功后执行无失败的 `commit` 并发布快照。

同一求解域中，只要一个参与对象输出不合法，整个域的候选均回退。其他独立求解域可以继续提交。失败时保留该层的上游显示状态和求解器上次成功状态，禁止仅回退画面而继续推进隐藏状态。

同一动态刚体在一次模拟 tick 中只有一个时间推进者，跨层也不能再次积分同一时间间隔。后续层可以读取或修正姿态，但不得隐式推进时间，也不得覆盖前一求解实例的历史状态。需要联合反馈的计算必须归入同一个求解域，首版不提供跨效果隐式反馈。

同层显示顺序仍沿用当前运行时的覆盖规则。结构修改按其声明的完整写入集合参与竞争，不能只保留一次细分的骨骼而丢弃同次细分的 joint。失去结构写入权的候选必须整体丢弃，其历史状态不得推进。共享域只创建和提交一个候选。

暂停且关闭编辑模拟时不推进历史状态。启用编辑模拟时，由运行时按实际编辑时间生成固定子步。窗口刷新和快照查询不得新增子步。长时间间隔按有上限的步数处理，报告未消费时间，不采用负时间步或无限补算。

向后跳帧、循环回到起点、场景重置、模型重载、结构改变、效果重新启用、效果移层以及标为需要重置的参数变化，均显式调用 `reset`。首版从当前动画姿态重建，不自动倒放或重演整段物理历史。设备丢失时，GPU 专用状态失效并触发重置；CPU 状态可保留，但必须重新建立其设备资源。

效果被禁用时释放其原生物理接管请求。仅最后一个接管者退出后恢复此前宿主物理模式。初始化失败或求解器不支持输入时也必须释放请求，不能留下「原生物理关闭，但新求解器未运行」的静默状态。

切换原生物理模式后，首次求解必须等待一份确认已按新模式生成的动画输入。旧快照只可用于保持显示，不能被当作未受原生物理影响的初始化姿态。

## FX 接入和查看窗口

原生算法接入沿用当前 FX 解析与参数系统。保留 `MMVPhysics="Bullet3"`，注册 `AVBD`、`SDS`、`VBD` 求解器值。重蒙皮使用新增 `MMVSkinning="DDM"`。一个效果实例不能同时声明两种原生处理类别。未注册、缺少 DLL 或缺少能力时明确报错，不退回 Bullet3。

HLSL 首版继续读取当前层 `MMVBones`、`MMVRigids`、`MMVJoints`，不增加任意结构写入 UAV。原生模块通过上述候选通道输出完整结构，再由运行时上传下一层所需 SRV。新增碰撞形状数据通过明确的只读资源表暴露，缺少相应后端能力时报告不支持。

查看窗口接入一个只读、带版本和释放函数的快照查询接口 `querySnapshot`。查询至少指定层、效果实例或求解域、对象，以及 `Source`、`Upstream`、`PreviousCommitted`、`Output` 四种阶段。`Output` 只表示最近一次成功提交，不暴露运行中的 `Candidate`。快照在显式 `releaseSnapshot` 前有效，不依赖当前 `evaluate` 的临时数组。

窗口要求如下：

- 提供骨骼、刚体、joint 三种查看类型，以及输入、输出切换。分别显示数量、结构版本、时间和历史状态是否有效。
- joint 行显示 A/B 刚体、绑定骨骼、局部连接框架、当前世界锚点、限位和有效状态。允许定位到关联刚体或骨骼。
- 刚体行显示来源、新增标志、形状类型、质量、惯量、速度和绑定骨骼。细分后的新项与原项可区分。
- 骨骼及材质分配列表仍读取所选层的上游结构。只有下一层才能分配本层刚生成的骨骼，不把当前层输出提前放进其输入列表。
- 查看窗口的行数和选择使用稳定身份。切换层、重排或重载后，失效选择清空并提示，不按旧索引选中另一项。
- 参数编辑沿用当前全局「应用」与关闭回退事务。实时姿态、速度和派生锚点只读；窗口不直接写宿主 PMX、骨骼或原生物理世界。
- 刚体和 joint 查看不创建新的效果分配范围。原有骨骼、材质展开入口及其右键许可规则保持不变。
- 循环状态、求解耗时和错误归属显示在对应效果或求解域。查询窗口本身不得调用 `evaluate`、推进时间或触发重置。

## 校验、降级与零层特例

提交前至少检查有限数值、容量、索引范围、骨骼父级无环、权重归一化、质量与惯量有效性、joint 引用、形状资源及稳定键唯一性。每条错误携带层、对象、效果实例和出错项身份。

必要能力缺失时返回 `UNSUPPORTED_CAPABILITY`。非法结构返回 `INVALID_OUTPUT`，求解失败返回 `SOLVER_FAILED`，过期快照返回 `STALE_INPUT`。错误码通过本接口定义，不改变现有宿主返回码含义。

首版不通过删骨骼、断 joint 或退回原始球盒形状来掩盖不支持。原生模块可明确提供近似模式，但必须作为配置选项和输出诊断记录。

0 层 `MeshOnly` 模式可以只替换最终网格。它保留上游结构用于查看，但将「结构与输出网格一致」标志设为假，不伪造新的骨骼或 joint 状态。该输出不允许后续重新蒙皮，也不能被当作可直接烘焙的骨骼动画。普通层不能使用此例外。

## 接口验收与交付

接口会话使用确定性测试计算模块验收，不等待真实 AVBD 或 DDM 实现。

| 场景 | 通过标准 |
| --- | --- |
| 同层与跨层 | 同层效果读取相同快照，下层读取合并后完整结构 |
| 结构扩容 | 新增骨骼、刚体、joint 和权重后，下层查询、展开、分配与蒙皮均访问新表 |
| 删除与重排 | 有效引用正确重映射，悬空引用拒绝且保持旧状态 |
| 关节同步 | 刚体位移或旋转后，joint 世界锚点与局部框架计算一致 |
| 反馈循环 | 连续多个固定步的输出成为本实例下一步历史输入，重复查询不增加步数 |
| 回滚 | 一个候选注入 NaN 或非法 joint 后，整个求解域输出、tick 和内部历史均不变 |
| 写入竞争 | 未生效的结构候选整体丢弃，不残留骨骼、形状或已推进的历史 |
