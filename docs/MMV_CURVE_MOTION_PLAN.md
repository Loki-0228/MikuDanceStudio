# MMV、附件曲线与 VMD 动作设计

状态：2026-09-27 的设计记录。用户已选定图二改独立浮窗的布局。本文描述待实现能力，不代表当前版本已经支持贝塞尔曲线、附件动作 VMD 或任意 FX 参数动作。已提供交互预览，实际 Win32 实现尚未开始。

## 已确认的范围

MMV 的材质主挂载页、骨骼主挂载页和 `.x` 附件共用曲线编辑基础。附件位置、旋转采用骨骼式姿态轨道。其余数值采用表情式参数轨道，并增加曲线信息。模型表情后续可以复用同一套曲线求值与编辑器。

用户最后一句“关键帧烘焙支持所有表示桦”暂按“全部表情通道”记录，尚未单独确认该笔误。当前方案把全部模型表情列入可选择的烘焙范围。

入口位于 `.x` 附件数值输入区附近，包含「曲线」「读取 VMD」「导出 VMD」「烘焙」。「曲线」打开本文所述的独立非模态浮窗。MMV 参数页可以打开同一编辑器，并传入当前绑定和参数。

### 表情与附件的入口图标

用户已提交的入口设计位于 [`ui/mmv-curve-launcher/`](ui/mmv-curve-launcher/README.md)，本次核对版本为 `5349960`。表情操作区和附件数值输入区共用该图标，点击后打开或激活同一曲线浮窗，并选中对应对象及通道。具体坐标由各参数行布局决定；本次只确认入口用途，尚未接入 Win32 控件。

沿用现有资产，不重新绘制设计：22、24 逻辑像素按钮使用 [`curve-launcher.svg`](ui/mmv-curve-launcher/curve-launcher.svg)，18、20 逻辑像素按钮使用 [`curve-launcher-compact.svg`](ui/mmv-curve-launcher/curve-launcher-compact.svg)。图标框为按钮边长减 4，按系统 DPI 缩放。正式控件使用系统按钮文字色及禁用色，并提供本地化「打开曲线编辑器」提示和可访问名称。正常、按下、焦点、禁用状态遵循资产说明。

### 附件操作区布局（用户截图已确认）

用户确认要移动的是附件操作区最上方的附件名称下拉框，不是左下插值类型，也不是附件父模型、父骨骼选择框。缩短附件名称框，将其右侧下拉箭头移到截图绿色 X 附近；腾出的最右侧位置放置正方形曲线编辑器按钮。保持这一排的总宽度，不覆盖右侧「显示」「阴影」控件。

```text
附件操作
[附件名称       ▾][曲线图标]  □显示
[ 载入 ][ 删除 ]              □阴影
[父模型       ▾][父骨骼       ▾]
 X[       ] Y[       ] Z[       ]
Rx[       ]Ry[       ]Rz[       ]
 S[       ]Tr[       ][读取][登记]
```

原附件文件按钮改为「载入」，仍负责添加 `.x` 文件。底部「登记」缩窄，左侧新增「读取」，专门把 VMD 动作读入当前选中的附件；不创建附件，不替换附件模型。两按钮须完整显示本地化短名称，不能以省略号或截字满足宽度。正式布局可略微收窄底行的数值输入框以留出间隔，但不能重叠。窄面板及 DPI 缩放须同时验收。

输入框采用三列共用网格：X／Rx／S 对齐第一列，Y／Ry／Tr 对齐第二列，Z／Rz 对齐第三列。每列标签右对齐，使用相同宽度的标签区和间隔；文字左边缘无需对齐，不能按标签字符数推移输入框。上下输入框的左右边界和高度一致，底行「读取」「登记」并排放入第三列，保持同高和完整标题。语言切换、字体与 DPI 改变后重新按实际文字度量布局。

文本不得贴住控件边缘：外部标签与输入框、复选框之间至少留 4 个逻辑像素，输入框与下拉框的框内文字左右各保留至少 4 个逻辑像素，并为下拉箭头单独保留空间。框内文字上下须有余量，不能以过低的控件高度裁切字形。标签区宽度按最宽文本确定，宽度不足时调整控件或面板尺寸，不压缩这些间隔；100%、125%、150% DPI 及三语均适用。

左上「文件」菜单新增「读取当前附件动作（VMD）…」，与面板「读取」复用同一处理函数。操作目标始终为当前附件选择框中的附件，不由当前模型、相机模式或 VMD 内的模型名称猜测。文件选择和范围确认显示目标附件名；目标删除、无附件或读入期间不可编辑时禁用入口。读取失败保持原动作，成功后统一刷新当前帧、附件参数、曲线浮窗和撤销状态。

## 界面布局（用户已选定）

用户在旧图二布局上选定编辑器形态，并把编辑器改为独立非模态浮窗。浮窗不阻塞主窗口，可以与主窗口的时间轴和视口同时使用。旧图二布局里的 3D 视口占位删除：视口仍由主窗口提供，浮窗不再内嵌视口，避免与主视口争夺渲染时机和输入焦点。

浮窗分为四区：

| 区域 | 内容 |

| 左下 | 原版 MMD 贝塞尔局部区间手柄 |
| 右下 | 关键帧数值与切线属性 |
| 左侧 | 通道树 |

此前的 A、B、C 三个候选已被本次选择取代，不再作为待决项。方案 A 的内嵌展开、方案 B 的原版左下角曲线面板、方案 C 的通用非模态窗口只保留为讨论记录。

交互预览覆盖数值与速度视图切换、关键帧及手柄拖动、0–127 坐标读数、切线速率与影响长度输入、整帧吸附、平移缩放、适配全部与适配区间。「浮窗视野导航」一节的范围条拖动、滚轮缩放与键盘导航已加入预览并通过后台浏览器核对。正式编辑器的框选、多键编辑和对象树父项选择不属于本次预览。读取、导出和烘焙仅演示范围选择，不读写工程或生成 VMD。

正式编辑器在浮窗中显示对象、所属挂载页、材质或骨骼范围、参数及分量。选择时间线区间后，手柄编辑该区间的曲线。原版风格使用归一化的时间和数值进度。自定义切线提供数值编辑，不能只显示预设按钮。向量参数支持逐分量编辑和同时应用。

## 曲线编辑器交互规则

下面两类规则要分开看。传统规则取自 Adobe 官方动画基础说明（链接见「核对依据」），属于通用动画编辑器的做法。本项目选择是本项目在这些通用做法上的具体决定。

| 项目 | 传统规则 | 本项目选择 |
| --- | --- | --- |
| 时间轴方向 | 时间沿横轴展开，关键帧按时间排布 | 时间横向、数值纵向；数值视图与速度视图共用同一条时间轴，播放头与选中帧同步 |
| 视图类型 | 数值视图与速度视图分别显示同一动画 | 两个视图都保留；数值视图编辑关键帧数值与切线，速度视图读取和调整变化率 |
| 通道显示 | 各属性通道独立成行，可以折叠 | 通道树按 `.x` 附件、MMV 材质主挂载页、MMV 骨骼主挂载页、模型表情分组；x、y、z 等分量各自成行 |
| 关键帧选择与拖动 | 可以单选、框选、整体拖动关键帧 | 支持单选、框选、整体拖动和数值时间输入；改时间与改数值都写回同一份关键帧数据 |
| 吸附 | 吸附到帧、关键帧和标记 | 默认整帧吸附；关闭后允许连续拖动预览，首版提交仍按原生整帧存储并显示最终帧号。子帧关键帧需要另行扩展格式，不作为首版承诺 |
| 平移缩放 | 水平缩放时间、垂直缩放数值，滚轮配合修饰键 | 两个视图共享水平时间范围，垂直数值范围分别缩放；范围条拖动、滚轮与键盘的具体按键见「浮窗视野导航」一节 |
| 适配 | 适配全部关键帧或适配选中 | 提供适配全部与适配选中；速度视图的垂直范围单独适配，避免把不同量纲压在同一条纵轴上 |

## 浮窗视野导航

本节规则作用于浮窗上方曲线编辑区的画布，以及画布的时间范围条和数值范围条。范围条中央拖动平移、两端拖动缩放是用户本轮要求。滚轮平移、修饰键缩放及中键拖动的按键参照 Adobe After Effects 官方说明，具体对应见下表。

### 视野导航与当前帧滑块的区别

当前帧滑块定位播放时间。视野导航只改变画布显示的时间范围和数值范围，两者是两套独立操作：

- 不改变任何关键帧的时间与数值，不写关键帧数据。
- 不进入撤销栈，不触发烘焙，不产生需要撤销的事务。
- 不移动当前帧，不改变播放状态和播放头所在时间。
- 画布上的缩放和平移不得落到关键帧拖动上，拖动关键帧也不得改变视野。

### 时间范围条与数值范围条

画布在横向上带一条时间范围条，数值视图和速度视图在右侧各带一条纵向数值范围条。

| 拖动位置 | 行为 |
| --- | --- |
| 时间范围条中部 | 平移时间范围，保持当前时间跨度不变 |
| 时间范围条左端 | 缩放时间范围，固定右端时间 |
| 时间范围条右端 | 缩放时间范围，固定左端时间 |
| 数值范围条中部 | 平移数值范围，保持当前数值跨度不变 |
| 数值范围条上端 | 缩放数值范围，固定下端数值 |
| 数值范围条下端 | 缩放数值范围，固定上端数值 |

两端不能交叉。预览最小时间跨度为 1 帧，最小数值跨度为 0.00001；正式实现须按通道单位确定合理的精度下限。拖动到最小跨度后停止收缩，避免跨度为零造成除零。视野很小时，范围条的两端手柄和中部拖拽区仍保留最小可点击尺寸；其视觉宽度可能不再与范围严格成比例，精确范围由读数表示。触摸模式三段各至少 44 逻辑像素。

范围条的中部与两端都可以用键盘操作。手柄取得焦点后，方向键执行与鼠标拖动相同的平移或缩放：时间每次调整 1 帧，数值每次调整当前跨度的 2%，Shift 加方向键按十倍步长调整。

滚轮缩放锚定鼠标指针所在位置。横向缩放的锚点是指针当前指向的时间，纵向缩放的锚点是指针当前指向的数值，缩放过程中锚点保持在指针下不动。中键拖动和空格加左键拖动只平移画布，不改变缩放比例。

滚轮仅在画布内执行导航。V、H、F 和 Home 在指针位于画布内或编辑器持有键盘焦点时生效，但不截获输入框、数值输入、下拉框的按键。空格平移只在画布交互期间启用，焦点在普通按钮时仍执行按钮的原生空格操作。输入控件内的滚轮按控件自身行为处理。

按下空格或中键时，即使指针压在一个关键帧上，也优先进入导航分支，不选中、不移动该关键帧。松开空格清除临时工具；已开始的平移保持指针捕获，离开画布后仍可继续，直至松开鼠标或取消拖动。离开画布只清除悬停状态，窗口失去焦点则清除临时按键并结束拖动，防止下次操作沿用残留状态。

浮窗内提供可展开的快捷键说明，默认收起。展开后列出本节全部按键、范围条各段的拖动语义和缩放锚定规则，文案随浮窗界面语言显示。

### 视图之间的范围共享

数值视图与速度视图共享同一条横向时间范围，在任一视图平移时间或缩放时间，另一个视图显示同一段时间。纵向数值范围各自保留：两个视图的量纲不同，平移或缩放其中一个视图的纵向范围不影响另一个视图。

## 通道树

浮窗左侧的通道树列出全部可编辑通道：

- `.x` 附件：位置 XYZ、旋转 XYZ、统一缩放、透明度，以及离散的显示、投影开关、父模型和父骨骼。
- MMV 材质主挂载页：作者允许 K 帧的参数。
- MMV 骨骼主挂载页：作者允许 K 帧的参数。
- 模型表情：全部表情通道。

向量参数的 x、y、z 等分量各自成行，可以单独显示、单独编辑。父项提供全选和半选状态。通道树只负责选择，不改变各挂载页自身的绑定和取值方式。

## 速度视图

速度是数值视图所画同一条曲线的导数，单位是数值单位每秒。标量通道的速度带正负号，负值表示数值随时间下降。

位置这类向量通道按分量分别计算和显示速度。合速度模长只能作为派生预览显示，不能当作一条可编辑的速度轨道，也不能和分量速度放在同一行。

数值视图和速度视图编辑的是同一批关键帧和同一条切线。两个视图不能各自保存一条互相矛盾的速度轨道。在任一视图修改关键帧或切线后，另一个视图按同一曲线立即重算。

## MMD 局部手柄与完整曲线

原版 MMD 的 0–127 局部区间手柄是兼容视图，只能表达手柄允许范围内的入段与出段形状。完整 F-curve 还能表达等值端点之间的起伏和过冲，因此编辑器显示或写回完整曲线时，不能无提示地把数值钳到 0–127 手柄能表达的范围内。等值端点无法通过除以端点差来归一化。超出局部手柄表达能力的曲线须用完整曲线编辑，并提示该区间无法由原版手柄表示。

## 切线模式与显示

切线提供四种模式：

- 自由：入切线与出切线分别设置。
- 对齐：两侧手柄共线，入段与出段端点速率相同，影响长度可以不同。
- 水平：切线水平，在关键帧处形成平坦极值。
- 线性：目标区间两端都采用连接端点的割线斜率，使该区间速度恒定。只改变一个端点手柄不算线性区间。修改涉及相邻关键帧时一并纳入撤销事务。

自动切线带防过冲规则：自动切线若会在相邻关键帧之间产生超出这两个关键帧数值范围的过冲，编辑器降低切线速率以消除过冲。该调整必须可见，并且能被手动切线覆盖。

每个关键帧显示入切线和出切线的速率与影响长度。速率决定曲线在关键帧处的斜率，影响长度决定两侧控制点沿时间轴的延伸距离。两项都可以分别编辑。

## 求值与边界情况

- 零分母：同一通道不得提交重复时刻。导入按明确的冲突规则处理，不构造零长度曲线。遇到无效时间切线时拒绝修改或回退，并报告原因，不输出非有限值。
- 离散键跳变：布尔、枚举、父绑定等离散通道按阶跃求值，跳变处的速度是脉冲，不能平滑成连续曲线。离散通道默认不显示速度视图。
- 向量单位不同：位置用长度单位，旋转用角度，透明度和参数用无量纲值或百分比。不同量纲的通道不能共用一条速度纵轴，适配范围按通道计算。
- 帧率：速度按每秒计算，等于每帧导数乘以动作时间基准的帧率。同样的帧号和值在更高帧率下播放，速度会变大。仅切换帧与秒的显示单位不改变动作；导出渲染帧率也不能暗中改写动作的时间基准。
- 显示与锁定：通道的隐藏和锁定只影响编辑与显示，不改变渲染启停，也不改变求值和烘焙结果。

## 曲线与关键帧语义

连续浮点通道支持阶跃、线性、现有平滑插值和自定义三次贝塞尔。布尔、枚举和父绑定采用阶跃。当前 MMV 整数参数也按阶跃求值，不能在扩展中无提示地改变既有行为。

贝塞尔求值先由时间求曲线参数，再取得数值进度。不得把时间直接当作曲线参数。手柄时间坐标保持可求逆，重复帧、零长度区间和非有限输入需要验证。原版 0–127 控制点模式与未来更广的切线模式须带独立版本或模式字段，不能改变旧数据含义。

新曲线段拟归属于结束关键帧的入段，与原版骨骼曲线的操作习惯对齐。当前 MMV 的 `parameters::Evaluate` 使用起始键 `before.interpolation`。实现必须版本化迁移旧段属性，不能仅新增字段后改变旧工程动画。

`.x` 的位置和旋转在本次审计的播放代码中按离散状态应用，缩放和透明度使用线性插值。扩展加入后，旧工程保持旧行为，只有显式设置曲线的通道采用新求值。

## VMD 必须保留原版可读取的标准数据

VMD 扩展只能追加在完整标准数据区之后。标准头、各段计数、记录布局和标准编码保持兼容。标准数据能表达的骨骼、表情、相机、灯光、自阴影、显示与 IK 数据仍写入对应标准段，不能全部迁入扩展。

本仓库标准写出器依次写完各段，并在显示与 IK 段结束后追加扩展。这里没有独立的通用“结束符”字节。本文中的“标准结束位置”指标准记录解析完毕的边界，不是额外插入的标记。

动作分为标准投影和完整扩展两部分：

- 真实模型的骨骼和表情按原有标准记录写出。新增表情曲线不改动标准表情记录大小。
- 附件位姿按骨骼式记录处理，其精确附件身份、欧拉角表达和绑定关系保存在扩展。标准骨骼记录采用四元数，单独使用该记录不能保留多圈欧拉角编辑信息。
- FX 数值采用表情式标量轨道。向量按分量保存，扩展保留参数稳定标识、类型、分量和所属绑定。
- 若把附件或 FX 数据投影为标准代理骨骼、代理表情，名称需要合法短名和冲突检测，扩展保存完整映射。原版仅能把这些记录应用到匹配的骨骼或表情，不会因此获得附件或 FX 控制能力。超出原版可表达范围的参数以扩展数据为准，导出界面说明损失。
- 新增曲线写入扩展。需要原版按帧呈现新增表情曲线时，标准表情部分写入烘焙样本，扩展另存原始稀疏关键帧与手柄。整数帧采样不等于任意子帧完全相同，采样步长须明确。

实际文件沿用已有容器方向：

```text
[完整标准 VMD 数据][版本化扩展数据][长度与尾部标识]
```

现有骨骼缩放使用 `MDSXVMDX` 尾部标识和 `MDSXMDSX` 版本 1 载荷。它是骨骼缩放专用布局，不能直接混入附件或 FX 字段。实现须演进为可容纳多个类型的版本化容器，兼容读取已有版本 1，并保留骨骼缩放数据。不能把两个独立扩展尾部简单串联，使其中一个读写器吞掉另一段。

扩展记录标准区长度与校验值。加载器先校验标准边界，再校验扩展长度、版本、校验值和条目边界。扩展无效时提示原因，并保留标准动作的加载结果。未知类型按长度跳过；可安全保留的未知条目随文件重存，不能误解释为已知类型。扩展应用作为独立事务，不提交部分参数或部分曲线。

通用动作读取器须按记录数量完整解析或跳过每个标准段，再确认追加边界。现有模型专用加载路径仅读取相机、灯光与自阴影的计数，不能直接作为任意混合轨道文件的通用解析器。

原版程序读取标准数据是验收要求。原版重存是否保留尾部扩展不能作为保证；扩展被丢弃后，标准动作仍须有效。原版 MMD 的运行时兼容性必须实测，不能只根据仓库头文件中的静态分析说明判定通过。

## 烘焙与动作范围选择

选择树包含模型骨骼、模型表情、`.x` 附件、MMV 材质主挂载页、MMV 骨骼主挂载页。对象之下列出子通道，支持父项全选和子项选择，父项显示半选状态。范围包含起止帧、采样步长和动作导入偏移。

附件连续通道包括位置 XYZ、旋转 XYZ、统一缩放与透明度。显示、投影开关、父模型和父骨骼属于离散通道。全部表情可批量选择。MMV 只列出作者允许 K 帧的参数，向量分量保留所属参数身份。

烘焙只替换选定通道和帧范围。当前附件键是整条记录，不能把未选分量写成当前帧值或默认值。已有目标帧键作为合并基底；无键帧先求值原动画，再合并所选样本。还需保留未选通道的原曲线区间与求值语义，不能因插入合并记录改变原动画。

计算结果先暂存，全部验证成功后一次性提交，支持撤销和取消。取样不能污染播放状态、物理状态或 MMV 的下一帧输入。原生附件与模型表情的结果进入 PMM，MMV 参数的结果进入 VMM。VEM 仍为静态预设。

此处烘焙的是通道数值。逐顶点变形、增删拓扑和材质生成不能仅靠位置、旋转或参数键保留，属于独立的网格缓存功能。
