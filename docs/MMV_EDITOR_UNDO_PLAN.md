# MMV 分配窗口撤销计划

状态：待实现。当前曲线编辑器的局部撤销不等于 MMV 整个分配窗口的撤销。

全局「应用」负责确认整个窗口的编辑；关闭窗口回退上次应用后的改动。这是编辑事务要求，也不能代替多步撤销。实现由 MMV 分层界面主会话统一安排。

计划覆盖分层配置、对象及骨骼／材质分配、FX 启停、参数和关键帧。一次连续拖动合并为一条撤销记录，撤销后发生新编辑时清空重做记录。不同页签的操作共用历史，不只记录当前 FX。

撤销历史只保存编辑数据；GPU 资源和物理运行状态按恢复后的配置重建。场景替换、对象删除、效果热重载、工程读取及帧率修正需要明确历史失效规则，防止恢复到已不存在的对象或层。

验收须包含跨页签连续撤销／重做、拖动参数、增删关键帧、效果移除、全局应用后再编辑并关闭，以及三语按钮状态。VMM 自动保存读取已确认配置，不写入待应用的预览或撤销历史。
