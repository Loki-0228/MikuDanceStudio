# TAA 与 SMAA T2x 的 GPU 运动历史优化

2026-10-14。本次改动减少时间抗锯齿的 GPU/CPU 往返和部分覆盖重绘，不改变 SMAA 1x、菜单、工程保存格式或时间采样数量。性能对比基准为本地 v2026.10.14.5 的固定提交 `3741fac9717178976799afcdb0979d07a44a8e14`；累计发布说明仍与正式发布 v2026.10.12.1 比较。

## 实现范围

- 变形后顶点的裁剪空间坐标写入 RGBA32F 纹理。当前帧和上一帧持有各自的结果，运动顶点着色器直接读取两帧，生成速度和深度，不再将这些捕获结果读回 CPU 再上传。
- 同时支持 MME 顶点着色器和原生固定功能变换。复用原始索引缓冲绘制运动场；仍在 CPU 检查索引、输入顶点与着色器状态，以识别 MME 同一帧内对输入的修改，避免错误复用。
- 输入一致的材质共享捕获结果。纹理和查找顶点缓冲池最多保留 256 MiB，只复用已无历史引用的资源；着色器补丁缓存最多 256 组。上述预算不包含颜色历史、运动场等其他 AA 资源。
- 只有已确认不透明、没有 MME、像素着色器、裁剪平面或裁剪矩形的原生实体材质才省去覆盖重绘。透明贴图和 MME 保留原着色器的覆盖检查，避免将被裁掉的像素带入历史。
- 按实际 D3D9 顶点纹理能力检测 NVIDIA、AMD、Intel，不使用厂商专用扩展。不支持 RGBA32F 顶点纹理读取或使用软件顶点处理时保留 CPU 兼容路径；不支持的运动绘制仍回退到单帧抗锯齿，不改写工程选项。

这没有将任意 MME 的运动场合并进首次材质绘制。复杂特效仍有额外绘制与输入检查成本，也没有声称所有 CPU/GPU 同步都已消除。

| 检查 | 本轮结果 |

| 原生、MME 实际场景 | 各 618 项通过，包含相机和骨骼运动、GPU 运动场读取及强制无顶点纹理能力回退 |
| 图片序列 | 749 项通过 |
| 最小版 UI | 677 项通过 |
| SMAA 1x 两档、重置及 150% 缩放 | 原生、MME 共 8 组旧新版截图逐字节一致 |

运动场比较使用测试专用读回，不在产品帧循环中增加读回。原生场景比较 24475 个有效像素，MME 比较 24379 个；两者覆盖掩码差异均为 0，运动与深度相对误差最大约 `7.6831e-6`，超过 `1e-4` 阈值的像素为 0。

一次代表帧中，原生路径捕获 2 次、复用 79 次，覆盖重绘 76 次、省略 5 次；MME 捕获 6 次、复用 39 次，覆盖重绘 45 次、不省略。两者捕获结果的 CPU 读回计数均为 0；这个计数不包括输入缓冲检查和测试截图读回。

第 0 帧静止图保持同一时间和姿态补采样：T2x 一张图片绘制两次，TAA 一张图片绘制八次。连续 T2x 的 0～2 帧输出三张图片、绘制四次；SMAA 1x 输出三张、绘制三次。缺少运动数据时一张图片只绘制一次。物理和时间推进仍按输出步执行。

原始 MSAA 的不同运行之间存在少量像素差异，旧版重复运行也能复现，未将它列为逐字节一致结果。详细计数保留在审核证据中。前序 CH4NGE 长舞蹈验证与阴影检查本轮没有重跑。

## 本机性能对比

同一 YYB 初音 PMX、配置与测试宿主，按 A-B-B-A 顺序运行，A 为优化前固定源码，B 为本次源码。原生和原配 MME 各四轮，所有进程正常退出。测量包含渲染和检查截图读回，计时器为 `GetTickCount64`；它衡量测试路径耗时，不是纯 GPU 时间或产品播放 FPS。

| 路径 | 算法 | 优化前平均 ms/帧 | 优化后平均 ms/帧 | 耗时下降 |
| --- | --- | ---: | ---: | ---: |
| 原生 | TAA | 103.06 | 53.18 | 48.4% |
| 原生 | SMAA T2x 标准 | 98.83 | 57.33 | 42.0% |
| 原生 | SMAA T2x 斜线与拐角增强 | 96.33 | 52.00 | 46.0% |
| MME | TAA | 88.98 | 39.31 | 55.8% |
| MME | SMAA T2x 标准 | 83.33 | 41.67 | 50.0% |
| MME | SMAA T2x 斜线与拐角增强 | 75.50 | 44.33 | 41.3% |

每条路径、每个版本的 TAA 合计 62 帧，每档 T2x 合计 6 帧。T2x 样本较少且计时粒度有限，不据此比较两档之间的快慢。只统计两版共同的测试段，排除本次新增的强制回退和运动场比对段。截图尺寸为 1463×914；原始分段时间和二进制、模型 SHA-256 均保留在 `evidence/temporal-gpu/abba-runs.json` 中。

GPU 捕获回归运行于 Intel UHD Graphics；未取得 AMD 实机或其他显卡的性能结论。所有测试关闭 NVIDIA 补丁写入，不改动驱动设置。不同工程、复杂 MME、分辨率和机器负载可能有不同收益。
